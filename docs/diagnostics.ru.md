# Диагностика

[English](diagnostics.md)

Собирайте только данные, необходимые для воспроизведения проблемы. Проверяйте
вывод каждой команды и снимок экрана перед публикацией.

## Основные сведения

Запишите версию ExecWake и операционной системы:

```sh
execwake --version
uname -srmo
sed -n '1,20p' /etc/os-release
```

Укажите точный argv трассируемой команды, заменив секреты обозначениями. Уточните,
был ли stdin интерактивным, использовался ли TTY, а также код завершения или
завершающий сигнал дочернего процесса.

## Проблемы со сборщиком

Запустите минимальную трассировку с тем же пользователем и окружением, где
возникла проблема:

```sh
execwake run -- /usr/bin/true
```

Не публикуйте выведенный путь к сессии. В исходном репозитории можно получить
дополнительные сведения с помощью preflight-проверки Linux collector:

```sh
scripts/check-linux-collector.sh
```

В выводе preflight может быть путь cgroup или идентификатор контейнера. Проверьте
его перед публикацией. Не запускайте проверку с повышенными привилегиями, если
исходный запуск ExecWake выполнялся без них.

Если установлен `sqlite3`, следующая read-only команда извлечёт только метаданные
сессии и состояние покрытия:

```sh
session=/absolute/path/to/session.sqlite3
sqlite3 -readonly "$session" \
  'SELECT schema_version, mode, state, finalized, collector_backend,
          privacy_profile FROM session;
   SELECT category, state, lost_events FROM coverage ORDER BY category;'
```

Не публикуйте другие таблицы базы данных без проверки их содержимого.

## Проблемы с интерфейсом отчёта

Укажите название и версию браузера, текст ошибки, число событий и процессов, а
также воспроизводится ли проблема с новой сессией `/usr/bin/true`. На снимках
экрана могут быть пути и сетевые адреса трассируемой команды.

## Проблемы с производительностью

Укажите трассируемую команду и версию package manager, backend сборщика, число
событий, обычную длительность, длительность с ExecWake и наличие потерянных
событий в coverage. Используйте команду, которую можно безопасно опубликовать.
