# История изменений

## 0.1.0-rc.5 — 2026-09-15

- Flood-проверка eBPF допускает неполную запись под нагрузкой, только если в
  трассе зарегистрирована потеря событий и частичное покрытие.
- Добавлены явные тесты ограниченного суммирования потерь eBPF и классификации
  причин cgroup fallback.
- Повторяющиеся параметры `run` отклоняются; `diff --` позволяет передавать
  пути к сессиям, начинающиеся с дефиса.
- Документ `diff --json` получил версию формата и детерминированные счётчики
  поведения, findings и несопоставимых категорий.
- Golden-тест фиксирует машинный формат; готовые пакеты проверяются на экспорт
  сессий, JSON-вывод и коды завершения diff.

## 0.1.0-rc.4 — 2026-09-14

- Финальное чтение буфера eBPF теперь учитывает все оставшиеся события, а
  перегрузка переводит покрытие в частичное.
- Добавлены ограниченные коды ошибок запуска eBPF и обязательные проверки
  автоматического fallback на ограниченных runner Ubuntu 24.04.
- Усилена остановка сборщика, передача сигналов и финализация сессии при ошибке
  запуска.
- Отчёт и diff открывают только для чтения сессии, записанные первыми тремя
  release candidate.
- Добавлен `run --output` для экспорта завершённой сессии без перезаписи
  существующего пути.
- Добавлены детерминированный вывод `diff --json` и включаемые явно коды
  завершения для изменённых и несопоставимых результатов.
- Добавлены smoke-тесты пакетов в Debian 12 и предел совместимости GLIBC 2.35
  для release-артефактов amd64 и arm64.

## 0.1.0-rc.3 — 2026-09-06

- Добавлен явный выбор collector: `auto`, `ebpf` или `ptrace`.
- В манифестах сессий и отчётах сохраняются запрошенный collector, выбранный
  backend и ограниченный код причины fallback.
- После завершения запуска выводится сводка с учётом фактического покрытия.
- Добавлена непривилегированная проверка ptrace на Ubuntu 22.04 и 24.04 для amd64
  и arm64.
- Добавлены проверка встроенного eBPF-объекта и расширенная матрица совместимости
  eBPF.
- Воспроизводимость release-архивов теперь проверяется автоматически, а
  публикация релиза явно привязана к репозиторию.
